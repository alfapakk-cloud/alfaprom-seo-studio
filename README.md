`index.html` — Quality Engine 1.4: автоматическая оценка 23 критериев, доработка и независимая повторная оценка через помощника α SEO. [Сценарий работы, ограничения и проверка релиза](docs/QUALITY_ENGINE.md). Исходный контекст серии чатов сохранён отдельно.

Для локального просмотра без установки зависимостей:

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000`. Очередь хранится отдельно для каждого браузерного профиля и адреса сайта; локальный запуск не подхватит очередь с GitHub Pages. Не считать демонстрационную MAP-статью фактическим содержимым проекта пользователя.

Автоматическая доработка по подписке: [инструкция помощника](helper/README.md). На текущем Mac установлен ALFAPROM Helper.app; запуск — кнопкой «Запустить помощника» в студии. Первый переход по системной ссылке требует ручной проверки: инструмент автоматизации его заблокировал.
