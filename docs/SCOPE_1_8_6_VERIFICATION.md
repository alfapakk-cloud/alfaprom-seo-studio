# Три действия и точная область оценки 1.8.6

## Интерфейс

Три основные кнопки: «Запустить оценку всей статьи» (все 23), «Запустить оценку исправленных критериев» (только исправленные номера), «Исправить N критериев» (только выявленные замечания, без оценки). До внесения правок вторая кнопка недоступна. Она никогда не заменяется полной оценкой скрыто. Первой кнопкой можно явно оценить весь подготовленный вариант. После подготовки правок следует использовать вторую кнопку.

Исправление шести пунктов передаёт GPT на повторную оценку ровно эти шесть номеров, без расширения по матрице зависимостей. Счётчик, очередь и адресные запросы используют один сохранённый набор. У остальных сохраняются прежние оценки, основания и даты, с пометкой «Сохранена прежняя оценка». Локальная проверка реальных дефектов HTML/объёма/ссылок продолжает блокировать неверную готовность, но не вызывает дополнительные запросы GPT.

У полосы показано, например, «Оцениваем исправленные критерии: 1–5 из 6», затем «6 из 6», оценка оставшегося времени и отдельный процент этапа. Завершённые пункты отражаются в счётчиках сразу.

## Продолжение

Контрольные точки 1.8.5, в которых шесть исправлений разрослись до 18 зависимых проверок, восстанавливают исходные исправленные номера из fixDoneIds/плана/истории. Текст, изображения, источники и уже завершённые оценки нужных пунктов сохраняются; ненужная часть старой очереди исключается. Кнопка оценки исправленных продолжает только оставшиеся номера, без повторных патчей и повторения готовых групп. Номера уже завершённых оценок принимаются только при совпадении fingerprint сохранённого рабочего текста.

Исправлена идентичность текущей статьи при наличии сохранённого генерационного черновика: чужой draftId больше не меняет токен текущей статьи и не мешает распознать её контрольную точку. Временные непроверенные статусы не превращаются в новые задания на исправление.

Замечание GPT за пределами запрошенной группы адресной оценки отклоняется и фиксируется в диагностике, не увеличивая очередь и не меняя посторонние оценки. Внутри выбранной группы сохраняются проверки цитат/противоречий и один ограниченный повтор из 1.8.5. Чужая версия, неправильные номера, ложные источники и неподходящий HTML по-прежнему блокируются.

## Верификация

270 автономных DOM-сценариев пройдены. Включены 11 новых сценариев трёх кнопок, 6→6 без 18, сохранения 17 остальных оценок и дат, явного полного аудита 23, продолжения 5/6, миграции старой очереди 18→6, текущей статьи с сохранённым черновиком, посторонних замечаний и блокировки реального локального дефекта без дополнительных GPT-запросов. 3 нативных сценария canvas/WebP/курсора пропущены из-за ограничений DOM-среды. Реальная пользовательская статья не читалась и не оценивалась агентом.

Бэкенд, генерация, мост, схема, источники, модель gpt-6.1-sol/high и протокол 11 сохранены. Оплата API не добавлена. SEO-план и стратегия не менялись. Программные ZIP и подпись приложения проверены; статей, изображений пользователя, профилей, паролей и сессий в архивах нет.

## Включение

Остановить прежнюю оценку 18 пунктов, обновить локальную студию ⌘R и нажать «Запустить оценку исправленных критериев». Перезапуск помощника и новая генерация статьи не нужны. Полный аудит 23 запускается только отдельной кнопкой «Запустить оценку всей статьи».
