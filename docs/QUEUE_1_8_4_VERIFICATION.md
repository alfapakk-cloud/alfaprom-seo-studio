# Очередь и прогресс исправлений 1.8.4

## Что изменено

- В заголовке непосредственно у полосы: «Исправляем критерий 2 из 5: № … — название». На отдельной строке там же — ориентировочный диапазон времени до завершения всей очереди. Замеры завершённых запросов уточняют оценку; при превышении оценки это обозначается явно. Процент относится к текущему этапу.
- По одному критерию на точечный патч. Очередь сохраняет порядок и общее число; уже пройденные пункты пропускаются. Новый реально обнаруженный недостаток добавляется явно, с пояснением.
- Исправление и независимая проверка результата названы по-разному. Остальные затронутые проверки объединяются в завершающую очередь; изменения фактов проверяются сразу. Для определения масштаба правки учитывается реальная разница текста, а не длина всего исходного абзаца; ограничение буквальной замены до 40% сохранено.
- Каждый критерий получает не более одного принятого автоматического исправления за запуск; отклонённая из-за объёма правка допускает один безопасный повтор. Возврат к ранее встречавшемуся состоянию текста отклоняется. Неуспех сохраняет красный/непроверенный статус, а не искусственный pass.
- Обычный запуск исправлений сам использует совместимую контрольную точку. Сохраняются очередь, завершённые и ожидающие группы аудита, принятый текст, попытки, измерения времени, полученные изображения и проверка ссылок. Статья не заменяется до завершения проверенного прохода. Незавершённый патч может потребовать повторного запроса после таймаута, но принятый патч не запускается повторно.
- Последняя завершённая проверка рабочего варианта видна во время исправлений, с явной пометкой версии. Промежуточные перенесённые оценки не выдаются за итоговую проверку новых правок.
- Дублирующая панель «Что нужно исправить» удалена из интерфейса. Точные цитаты, основания и действия доступны внутри соответствующего пункта списка 23 критериев, с экранированием недоверенного текста.

## Проверка

243 автономных сценария DOM прошли. В них 13 новых сценариев реального планировщика с поддельным транспортом: последовательность 1/5 → 2/5 в самом заголовке, оценка времени, ограничение повторов, продолжение обычной кнопкой, сохранение аудита и очереди, объединение зависимостей, блокировка A/B/A, отсутствие ложной готовности, сохранность оригинала и перенос замечаний в критерии. Ещё 3 сценария нативного canvas/WebP/позиции курсора пропущены из-за ограничений DOM-среды. Это проверки программной логики, а не повторная проверка пользовательской статьи.

Бэкенд, генератор, мост, схема и проверка источников побайтово совпадают с 1.8.3. Модель gpt-6.1-sol/high, вход через подписку ChatGPT, протокол 11, политика источников и все 23 критерия сохранены. SEO-план и стратегия не изменены. Платный API не добавлен. Профили браузеров, статьи, изображения и аккаунты пользователя не читались.

## Использование

После завершения или остановки текущей попытки обновить локальную страницу (⌘R) и нажать «Продолжить исправления». Перезапуск помощника и новая генерация статьи не нужны. Точное время ответа GPT заранее неизвестно; диапазон времени — оценка оставшейся работы.
