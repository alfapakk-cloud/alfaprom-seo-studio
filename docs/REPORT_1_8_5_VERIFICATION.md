# Оценка и исправления 1.8.5

## Поведение

В разделе качества два основных действия: **Запустить оценку** и **Исправить N критериев**. Оценка получает только отчёт; исправление получает только буквальные адресные патчи. Нет начальной, промежуточной или завершающей скрытой оценки внутри кнопки исправления. Без актуального отчёта исправление недоступно. После внесения правок отдельное нажатие «Запустить оценку» проверяет подготовленный вариант по изменённым и зависимым пунктам. До этого он явно помечен «Исправления ожидают оценки»; пройденные статусы не присваиваются за факт правки.

Принятые патчи, очередь, источники, изображения и история сохраняются в контрольной точке. Той же кнопкой продолжается только незавершённый патч; готовые фрагменты не переписываются повторно. Контрольные точки 1.8.4 с принятыми правками мигрируют в ожидание явной оценки. Текущая статья и резервная версия защищены от применения неподтверждённого кандидата; сохранение нового черновика после оценки включает его подготовленный HTML и собственный отчёт.

## Ошибка «Замечание не соответствует статье или оценке»

Ранее любой неподходящий элемент issues отклонял всю полученную группу. Теперь корректные оценки сохраняются. Несуществующая цитата, противоречие pass/na с замечанием, неверный формат и чужой номер в частичной проверке оставляют соответствующий пункт **непроверенным** с понятной причиной. Исключённое замечание не превращается в pass. Допускается один уточняющий запрос только по спорным номерам, без патчей и без повторения корректных групп; лимит сохраняется при перерыве. При повторной неудаче пункт остаётся незакрытым.

Кавычки, тире и пробелы сопоставляются детерминированно. Сохраняется настоящая непрерывная цитата статьи. Пересказ, склейки и несуществующие фразы не принимаются. Чужие fingerprint, версия, исполнение модели, несуществующие номера критериев, недопустимые факты и источники по-прежнему отклоняются.

## Обновление

Завершить либо остановить текущую попытку, обновить локальную страницу ⌘R. Перезапуск помощника и новая генерация статьи не нужны. Для ранее сохранённых правок, ожидающих проверки, использовать «Запустить оценку». Затем при необходимости «Исправить N критериев» и снова «Запустить оценку».
