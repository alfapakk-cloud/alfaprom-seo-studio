# Проверка α SEO 1.5 — 26 октября 2026

Проверена реализация встроенного генератора через ChatGPT-подписку. Платный API не используется.

- 111 браузерных регрессионных сценариев прошли, включая прежние 90 сценариев Quality Engine. Проверены актуальный промт с 23 критериями, исследование и SEO-поля, профили 3/6/11 изображений, контроль объёма, запрет фиктивных файлов, реальные места вставки, защита исходной статьи, применение и восстановление отчёта, ZIP/CRC32, остановка и устаревшие ответы.
- 28 Python-тестов прошли: схемы ответов, фиксированные модель и High, принудительный вход через ChatGPT, отсутствие API-перехода, включение встроенного imagegen только для изображений, проверка WebP, постоянное хранение файлов, Host/Origin/ключ сеанса, ограничения чтения файлов и отмена.
- На изолированном HTTP-контуре пройдены текст → 3 WebP → оценка; перегенерация одного слота, остановка с сохранением других двух файлов и продолжение только недостающего; применение и перезагрузка страницы с повторным получением всех изображений из хранилища. Содержимое рабочего проекта пользователя не заменялось.
- Реальный запрос `gpt-6.1-sol`, reasoning `high`, ChatGPT-аутентификация создал статью о MAP на 1928 видимых знаков. Встроенный imagegen создал три различных изображения; браузер сохранил настоящие WebP: обложка 1680×720 и два внутренних 1280×853. Проверены изображения и их расположение.
- Реальная последующая редакционная оценка вернула все 23 критерия. Два замечания и шесть критериев с недостающими подтверждениями остались видимы; генератор не объявляет такую статью готовой к публикации. Визуалы автоматически не утверждаются.
- Скачанный ZIP реальной статьи содержит HTML, SEO.txt, manifest.json и три соответствующих WebP; Python `zipfile.testzip()` не выявил повреждений. Метаданные модели и отчёт сохранены в манифесте.
- Приложение macOS 1.5 / build 7 собрано, подпись проверена, обновление установлено. После ручного перезапуска пользователем рабочий `/health` отвечает протоколом 7, новая страница показывает подключение помощника и выбор трёх форматов. Прежние статья, сохранённая версия и действующий отчёт сохранились.

Для повторения тестов:

```sh
PYTHONPYCACHEPREFIX=/private/tmp/alfaprom-pycache python3 -m unittest discover -s helper -p 'test*.py'
python3 docs/tests/build_browser_harness.py
python3 -m http.server 8765
```

Открыть http://127.0.0.1:8765/.quality-tests.html. Тестовая страница использует отдельный ключ хранилища. Реальные запросы модели намеренно не входят в регрессионную страницу: она не расходует лимиты подписки.

Большие форматы проверены структурно и на тестовых ответах; полный реальный прогон с 6 и 11 изображениями отдельно не запускался. Лимиты и длительность генерации зависят от аккаунта.

Дополнительно проверен явный переход из генератора GitHub Pages в локальную студию с сохранением проекта; при блокировке HTTPS → localhost показано действие для перехода вместо повторного совета перезапуска.

Для опубликованного скрипта задана версия URL, чтобы прежний браузерный кэш не скрывал обновление интерфейса. Версия параметра поддерживается сервером; нативная страница сохраняет совместимый URL и no-store.
