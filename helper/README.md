# Локальный помощник АЛЬФАПРОМ

Это небольшая программа на компьютере пользователя. Она принимает одно задание из Quality Engine, вызывает установленный официальный Codex с входом через ChatGPT, возвращает HTML для просмотра и замены в студии. Подписка расходует обычные лимиты Codex/ChatGPT; отдельный API-ключ не требуется.

## Как пользоваться

На текущем Mac установлен **ALFAPROM Helper.app** в личной папке Applications; ссылка `alfaprom-seo://start` зарегистрирована в macOS.

1. В Quality Engine, в блоке доработки нажать **«Запустить помощника»**. Если браузер запросит открытие приложения — подтвердить запуск.
2. Помощник появляется в строке меню Mac как **α SEO**. На странице студии появится зелёный статус «Программа активирована · помощник подключён». Далее нажать **«Доработать через Plus»**. Отдельного окна помощника нет.
3. Во время доработки видны этап, полоса с приблизительным процентом, прошедшее и ориентировочное оставшееся время. Генерация ограничена 90%, проверка — 95%, и только принятый результат даёт 100%. Просмотреть вернувшийся HTML с жёлтой подсветкой добавлений и отдельным списком удалений → «Применить и проверить заново». Старая версия доступна для восстановления и сравнения.
4. Остановить сервис или завершить приложение можно из меню **α SEO**. Остановка завершает и активный запрос доработки.

Первый реальный переход по системной ссылке в этой сессии инструмент браузерной автоматизации запретил своей политикой безопасности. Сборка, подпись, установка и регистрация проверены; открытие кнопкой предстоит подтвердить пользователю вручную. Ограничение инструмента не выдаётся за успешную проверку запуска.

На другом Mac с Apple Silicon: распаковать `alfaprom-mac-helper.zip` и один раз открыть ALFAPROM Helper.app для регистрации обработчика. Нужен установленный официальный Codex с входом через ChatGPT. Для старого варианта совместимости оставлен файл `Запустить помощника.command`.

Помощник не запускается при входе в систему: запуск — только по кнопке или открытию приложения. Он не открывает чат и не отправляет статью до отдельного нажатия «Доработать через Plus». Внешний вариант «Скопировать и открыть ChatGPT» и возврат HTML-файла остаются доступны.

## Стоимость и ограничения

Используется ChatGPT-вход официального Codex. Помощник принудительно задаёт `forced_login_method="chatgpt"` в реальном запросе, запрещает API-режим, убирает API-ключи из окружения дочернего процесса и принудительно выбирает ChatGPT-аутентификацию. При ошибке лимита запрос останавливается, другой платный провайдер не выбирается. Помощник не покупает кредиты, не меняет настройки подписки или её оплаты. Доступность и лимиты определяются аккаунтом OpenAI.

Codex по подписке не равен открытию той же истории обычного ChatGPT-чата: это отдельный запрос к доступной в Codex модели. История и память чатов не переносятся; полный контекст статьи входит в задание. Автоматически подтвердить истинность фактов такой запрос не может.

## Технические границы

- Сервер слушает только `127.0.0.1:8766`, без публичного доступа.
- Передача со студией — через фоновый локальный iframe и postMessage с проверкой origin, окна-отправителя, идентификатора задания и версии статьи. Браузер не отправляет API-запросы к OpenAI.
- HTTP-запрос принимается только из собственного локального iframe со случайным ключом сеанса. Ключ остаётся в iframe и не передаётся студии. CORS для сторонних сайтов не включён; Host проверяется. CSP разрешает встраивание только с домена студии и локального тестового сервера.
- Пароли и токены ChatGPT не читаются приложением и не передаются в студию. Их обслуживает официальный Codex.
- Локальная конфигурация сторонних провайдеров/MCP не загружается. Задание выполняется во временной папке с sandbox read-only, без shell-инструмента и сохранения сессии. Максимум один запрос одновременно, тайм-аут 15 минут.
- Исходная статья заменяется только кнопкой пользователя; новая версия проходит проверку заново.

Официальные основания: [Codex в автоматизации](https://learn.chatgpt.com/docs/non-interactive-mode), [вход через ChatGPT и API](https://learn.chatgpt.com/docs/auth), [лимиты тарифов](https://learn.chatgpt.com/docs/pricing).

## Сборка и проверка

Исходники приложения: `macos/Launcher.swift`, `macos/HelperURL.swift`. Сборка выполняется командой `python3 helper/macos/build.py`: создаётся подписанное локально приложение во временной папке и архив в корне проекта. Системный обработчик разрешает только команду запуска; параметры, пути, имена файлов и учётные данные через URL не принимаются.

Установка для текущего пользователя: `python3 helper/macos/install.py`. Обновляется только собственное приложение с идентификатором `org.alfaprom.seo-helper`; чужое приложение в папке назначения не перезаписывается.

Версия 1.2 / протокол 3: при обновлении остановить сервис через меню α SEO и запустить снова. Уже выполняющаяся задача продолжает работать в старом процессе до ручной остановки. Новая студия не открывает прежнее отдельное окно.

Проверки релиза: браузерные регрессионные сценарии, тесты Python, тестовый цикл доработки/отмены без вызова GPT, сборка и подпись приложения. Последний реальный запрос доработки проверен в предыдущем релизе. Этапы читаются из официального `codex exec --json`; текст событий, промт, пути и данные аккаунта не передаются в отчёт прогресса.

Сравнение строится по блокам и словам на копии DOM: подсветка не меняет HTML статьи, промт или экспорт. После применения сравнение доступно по сохранённой предыдущей версии. При смене статьи или анализа во время запроса результат остаётся доступен для скачивания. Ориентир времени основан на объёме текста и может быть превышен; максимальная длительность запроса — 15 минут.

Тесты Python: `PYTHONPYCACHEPREFIX=/private/tmp/alfaprom-pycache python3 helper/test_helper.py`.



## Version 1.3 / protocol 4: local Studio

Some browsers do not deliver the HTTPS-to-loopback iframe connection. The explicit button opens the complete Studio at http://127.0.0.1:8766/studio in the same tab. A form POST carries the current project in the request body, not in the URL. Host and Origin are validated; the transfer never starts inference. JSON is safely embedded as non-executable data. The local page and helper share one origin.

The first transfer preserves the full project, including queue and quality snapshots. If a local project already exists, it stays selected; the incoming project can be accepted explicitly and the previous local project is backed up for restoration. Website and local browser storage are separate. Continue editing locally after transfer, and export JSON backups. There is no automatic synchronization back to GitHub Pages.

The installed app bundles studio.html. Public endpoints remain health metadata and page content; generation and account diagnostics require the local session nonce. The native process was restarted by the user and verified as protocol 4 with ChatGPT authentication. Regression checks: 74 browser scenarios, 14 Python tests, and a complete mock transfer/revision cycle without inference. Real revision validation is tracked in the local project audit.


1.3.1 / protocol 5 removes the misleading login-status preflight from generation. The status command reads user configuration that may be unavailable to a background GUI process; actual exec ignores that configuration and enforces ChatGPT login directly. API keys are still removed from the environment, the provider is fixed to OpenAI, and there is no API fallback.


## Версия 1.4 / протокол 6: полный цикл качества

В Quality Engine появились две команды: «Проверить 23 критерия через α SEO» и «Исправить замечания и перепроверить». Первая получает структурированный редакционный отчёт прямо в студию. Вторая сначала оценивает исходный текст, исправляет найденные проблемы, затем независимо оценивает новый вариант; допускаются максимум две попытки доработки (до пяти последовательных запросов). Цикл останавливается при отсутствии изменений или по лимиту попыток.

Результат содержит HTML, Title/Description/H1, новую оценку всех 23 критериев, список закрытых замечаний и отдельные задачи по недостающим данным. При применении сохраняется именно отчёт новой версии. Предыдущие HTML, SEO-поля и отчёт доступны для восстановления. Ручной HTML после применения автоматически отправляется на полную оценку.

Редакционные критерии из автоматического отчёта сразу отображаются со способом проверки «Редакционная оценка GPT». Спрос, фактическая точность, источники, оригинальность, отсутствие каннибализации и доверие требуют подтверждений редактора; AI не закрывает их от имени человека. Для визуалов остаётся отдельный этап. Отсутствие данных не считается ошибкой статьи. Готовность к публикации автоматически не утверждается.

Новые операции `/audit` и `/edit` сохраняют прежние границы: loopback, точные Host/Origin, ключ сеанса, один запрос одновременно, ChatGPT-вход, отсутствие API-ключей и платного перехода. На каждый этап действует тайм-аут 15 минут. Процент относится к полному циклу, а ориентир оставшегося времени — к текущему этапу. После обновления работающий процесс нужно один раз остановить и запустить через меню α SEO, затем обновить локальную страницу студии.

Проверки: 89 браузерных сценариев, 17 Python-тестов; отдельный полный цикл через HTTP-макет помощника без модели. Реальный структурированный ответ GPT проверяется отдельно.
