# Локальный помощник АЛЬФАПРОМ

Это небольшая программа на компьютере пользователя. Она принимает одно задание из Quality Engine, вызывает установленный официальный Codex с входом через ChatGPT, возвращает HTML для просмотра и замены в студии. Подписка расходует обычные лимиты Codex/ChatGPT; отдельный API-ключ не требуется.

## Как пользоваться

На текущем Mac установлен **ALFAPROM Helper.app** в личной папке Applications; ссылка `alfaprom-seo://start` зарегистрирована в macOS.

1. В Quality Engine, в блоке доработки нажать **«Запустить помощника»**. Если браузер запросит открытие приложения — подтвердить запуск.
2. Помощник появляется в строке меню Mac как **α SEO**. Окно Terminal не нужно. Далее нажать **«Доработать через Plus»** в студии.
3. Просмотреть вернувшийся HTML → «Применить и проверить заново». Старая версия доступна для восстановления.
4. Остановить сервис или завершить приложение можно из меню **α SEO**. Остановка завершает и активный запрос доработки.

Первый реальный переход по системной ссылке в этой сессии инструмент браузерной автоматизации запретил своей политикой безопасности. Сборка, подпись, установка и регистрация проверены; открытие кнопкой предстоит подтвердить пользователю вручную. Ограничение инструмента не выдаётся за успешную проверку запуска.

На другом Mac с Apple Silicon: распаковать `alfaprom-mac-helper.zip` и один раз открыть ALFAPROM Helper.app для регистрации обработчика. Нужен установленный официальный Codex с входом через ChatGPT. Для старого варианта совместимости оставлен файл `Запустить помощника.command`.

Помощник не запускается при входе в систему: запуск — только по кнопке или открытию приложения. Он не открывает чат и не отправляет статью до отдельного нажатия «Доработать через Plus». Внешний вариант «Скопировать и открыть ChatGPT» и возврат HTML-файла остаются доступны.

## Стоимость и ограничения

Используется ChatGPT-вход официального Codex. Помощник перед каждым заданием проверяет `codex login status`, запрещает API-режим, убирает API-ключи из окружения дочернего процесса и принудительно выбирает ChatGPT-аутентификацию. При ошибке лимита запрос останавливается, другой платный провайдер не выбирается. Помощник не покупает кредиты, не меняет настройки подписки или её оплаты. Доступность и лимиты определяются аккаунтом OpenAI.

Codex по подписке не равен открытию той же истории обычного ChatGPT-чата: это отдельный запрос к доступной в Codex модели. История и память чатов не переносятся; полный контекст статьи входит в задание. Автоматически подтвердить истинность фактов такой запрос не может.

## Технические границы

- Сервер слушает только `127.0.0.1:8766`, без публичного доступа.
- Передача со студией — через отдельное окно и postMessage с проверкой origin, окна-отправителя, идентификатора задания и версии статьи. Браузер не отправляет API-запросы к OpenAI.
- HTTP-запрос на запуск принимается только из собственного локального окна с случайным ключом сеанса. CORS для сторонних сайтов не включён; Host проверяется.
- Пароли и токены ChatGPT не читаются приложением и не передаются в студию. Их обслуживает официальный Codex.
- Локальная конфигурация сторонних провайдеров/MCP не загружается. Задание выполняется во временной папке с sandbox read-only, без shell-инструмента и сохранения сессии. Максимум один запрос одновременно, тайм-аут 15 минут.
- Исходная статья заменяется только кнопкой пользователя; новая версия проходит проверку заново.

Официальные основания: [Codex в автоматизации](https://learn.chatgpt.com/docs/non-interactive-mode), [вход через ChatGPT и API](https://learn.chatgpt.com/docs/auth), [лимиты тарифов](https://learn.chatgpt.com/docs/pricing).

## Сборка и проверка

Исходники приложения: `macos/Launcher.swift`, `macos/HelperURL.swift`. Сборка выполняется командой `python3 helper/macos/build.py`: создаётся подписанное локально приложение во временной папке и архив в корне проекта. Системный обработчик разрешает только команду запуска; параметры, пути, имена файлов и учётные данные через URL не принимаются.

Установка для текущего пользователя: `python3 helper/macos/install.py`. Обновляется только собственное приложение с идентификатором `org.alfaprom.seo-helper`; чужое приложение в папке назначения не перезаписывается.

Проверено: 13 вариантов URL, 58 сценариев студии, 8 тестов Python, подпись приложения и регистрация обработчика. Реальный запрос доработки проверен в предыдущем релизе; новая работа не меняет способ входа или оплаты.

Тесты Python: `PYTHONPYCACHEPREFIX=/private/tmp/alfaprom-pycache python3 helper/test_helper.py`.
